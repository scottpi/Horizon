### [EVE Online beginnt nach über zwanzig Jahren mit der Migration auf Python 3](https://simonwillison.net/2026/Aug/25/eve-online-move-to-python-3/) ⭐️ 8.0/10

EVE Online hat offiziell den Beginn seiner lang erwarteten Migration von Stackless Python 2.7 auf Python 3 angekündigt, nachdem das MMORPG seit seinem Start im Jahr 2003 und dem letzten größeren Upgrade im Jahr 2010 auf Python 2 lief. Für die Codebasis mit 2,4 Millionen Zeilen wird das Skript „futurize“ eingesetzt, gefolgt von einer sorgfältigen manuellen Prüfung von rund 20.000 Stellen mit unterschiedlichem Verhaltensmuster zwischen den Sprachversionen. **「Hintergrund」** Stackless Python ist eine modifizierte Variante der Programmiersprache Python, die Mikro-Threads anstelle von Betriebssystem-Threads unterstützt und daher besonders für stark skalierbare Multiplayer-Spiele wie EVE Online genutzt wurde. Python 2.7 hat im Jahr 2020 das offizielle Ende seines Lebenszyklus erreicht, weshalb der Betrieb alter Codebasen zunehmend aufwändiger und sicherheitskritischer wird.

**「Auswirkungen」** Die Modernisierung sichert langfristig die technologische Wartbarkeit von EVE Online und erleichtert die Integration moderner Bibliotheken in die gewaltige Codebasis.
